# Age of Empire Lite

使用 Godot 4.7 制作的 2D 即时战略首版原型。英格兰和法兰西共用经济、单位、建筑与指令系统；文明差异及平衡数值集中在 `scripts/game_data.gd`。画面采用程序绘制的临时图形，无需模型或外部贴图。

## 运行

用 Godot 4 打开 `project.godot`，或在项目目录执行：

```sh
make run
```

如 Godot 安装在其他位置，可执行 `make run GODOT=/你的/Godot/路径`。

## 操作

- 左键选择，拖拽框选，按住 Shift 可追加选择。
- 右键移动、采集、耕作农田或攻击敌人。
- 选择村民后在底部选择建筑，再点击地图放置；右键或 Esc 取消。
- 选择建筑训练单位；选择城镇中心升级时代。
- 底部命令网格中的编号 1–6 可用作快捷键；底部中间显示选中对象与生产进度，右下角小地图可点击定位。
- WASD / 方向键或将鼠标移到窗口边缘移动镜头，四角可斜向移动；滚轮缩放。
- 按 Esc 打开或关闭暂停菜单；暂停时显示系统鼠标，可移出游戏窗口。
- 摧毁敌人的城镇中心获胜。

## 当前内容

- 四种资源、村民采集、农田、人口上限、建筑施工、单位训练队列、四个时代。
- 英格兰：农田产出加成、长弓兵。法兰西：骑士首次冲锋加成、马厩训练加速。
- 电脑对手能够采集、升级、建造、训练和进攻。
- 目前胜利条件为摧毁城镇中心；暂未加入寻路避障、多人联机及正式美术资源。
