# 单位视觉尺寸

2026-10-01：19 种人物和骑兵的显示模型缩小到原来的 0.8 倍，改善与建筑的视觉比例。单位碰撞半径、速度和攻击数值保持原值。攻城器械与船只的默认倍率为 1。随后按要求另将建筑及建造格放大到 1.6 倍，见[最新建筑对比](../building-scale/README.md)；本页图片记录仅缩小人物时的效果。

## 调整入口

- `GameData.FIGURE_VISUAL_SCALE`：人物和骑兵的统一倍率，当前为 0.8。
- `GameData.UNIT_VISUAL_SCALES`：兵种倍率，例如 `"royal_knight": 1.05`。
- `unit.visual_scale`：单个 Unit 的倍率，默认为 1。

最终倍率是上述基础倍率、兵种倍率和实例倍率的乘积。例如人物实例设为 `visual_scale = 1.25`，最终显示倍率为 `0.8 × 1.25 = 1.0`。船只和攻城器械也支持兵种与实例倍率。

绘制时缩放模型的局部坐标轴，脚下位置及地面高度不随倍率移动。阴影同步缩放；血条位置随模型调整，宽度和厚度保持可读。2.5D 点击区域使用相同倍率并保留点击容错，脚下的点击区域继续依据实际碰撞半径。选中圈仍反映实际占地。头像按独立的框内适配尺寸显示。

缩放通过现有画布变换执行，不重新生成模型或修改动画几何。

## 验证

`tests/unit_visual_scale.gd` 实际渲染村民、长弓兵和重骑兵，在两种视角、两个镜头倍率下检查模型及阴影缩放、坡地锚点，并检查实例倍率、快照、点击和模拟尺寸，共 12 个渲染用例。

另外通过单位覆盖检查、360 种单位动画/快照渲染比较、选择测试、坡地移动与选中圈跟随、战斗规则和主流程 smoke 测试。
