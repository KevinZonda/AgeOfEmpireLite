# 鹿受惊后闪跳 PoC

在 80 人围攻、附近有鹿群正常活动的可见 PoC 中发现。原实现每 0.35 秒扫描一次威胁，受惊时直接把坐标改为 55 像素外；下一帧重新用出生位置加正弦偏移计算坐标，把鹿拉回原处。并非贴图闪烁，而是实际世界坐标反复跳变，且会不断使导航障碍缓存失效。

`tests/deer_movement_poc.gd` 在鹿旁 40 像素处放置一名士兵，逐帧记录真实鹿 `_process` 的位移和逃跑初期的反向运动。修复前 19 个断言中 14 个失败。

| 模拟步长 | 修复前最大单步位移 | 修复后最大单步位移 |
| --- | ---: | ---: |
| 1/120 秒 | 55.178 px | 0.667 px |
| 1/60 秒 | 55.356 px | 1.333 px |
| 1/30 秒 | 55.712 px | 2.667 px |
| 0.2 秒 | 59.309 px | 16.000 px |

修复为持续的逃跑目标，游荡速度 18 px/s、逃跑速度 80 px/s。扫描之间继续走向逃跑目标；逃跑结束后在当前位置附近游荡，不再返回旧出生点。空间桶查询后精确检查 75 像素威胁半径。移动沿途以不超过四分之一地形格的间距检查通行性，避免长帧跳过水域；实际发生移动时才通知导航更新。

19 个断言全部通过，覆盖四种步长、持续逃跑、脱离威胁、出生游荡不跳变、村民不惊扰鹿、尸体不移动和长帧不能跨越水域。包括本 PoC 在内的 8 个相关测试脚本通过，覆盖狩猎采集、羊、野猪、迷雾可见性和导航。`fog_rendering.gd:15` 的固定高地坐标断言失败，旧版对照目录也在同一行失败；未计为本次通过。
