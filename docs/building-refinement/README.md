# 民居、铁匠铺与市场模型细化

这轮为三种建筑加入共享的立体面片模型，同时更新俯视图、斜视图和选中肖像。建筑尺寸、费用和属性仍由原来的游戏数据决定。

- 民居：门阶、侧窗、空心烟囱，以及普通、门廊、侧屋三种固定外形。位置决定外形，迷雾记忆会保留相同外观。英格兰采用木架，法兰西采用四坡屋顶与石墙分层，中国采用曲面屋檐、红色梁柱和低院墙。
- 铁匠铺：砖炉炉口、炉火、作业棚、带尖角的铁砧、煤箱、工具架和水槽。
- 市场：条纹布棚、柜台、货物、麻袋和木箱；保留原来的石制标记。
- 三种文明使用各自的建筑配色和屋顶形式，门头与布棚保留玩家颜色。底座改为薄平台。
- 地图和肖像使用同一份模型，缓存面片与投影；面片按空间关系排序，点击区域覆盖可见屋檐、烟囱和棚下设施。

## 复现与验证

```sh
make run RUN_ARGS='--script tools/building_refinement_preview.gd'
make run RUN_ARGS='--headless --script tests/refined_building_occlusion.gd'
make run RUN_ARGS='--headless --script tests/refined_building_selection.gd'
```

旧模型对比使用环境变量 `RTS_BUILDING_BASELINE_VISUAL` 指向改进前的 `building_visual.gd`，运行同一预览脚本会输出 `before-` 图像。

验证结果：15 种外观，共 3,908 个可绘制面片；539 个独立深度采样没有发现遮挡错误。点击验证覆盖三个缩放比例和两个施工进度，共 23,448 个面片中心，并检查模型缓存与记忆外观一致性。后续军事建筑细化同步调整了共享屋顶的瓦线，以上统计与预览已按最终屋顶重新生成。现有的迷雾建筑记忆、选择、斜视图和基础运行测试也均通过。
