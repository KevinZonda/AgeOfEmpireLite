# 游戏数值映射

`manifest.json` 记录了 2026-09-27 抓取的资料来源。`tools/build_game_balance.py` 从英格兰、法兰西、中国的已归档单位详情中提取本游戏已有的 21 条兵种线，生成 `data/aoe4_balance.json`。重新生成：

```sh
python3 tools/build_game_balance.py
```

运行时通过 `RtsBalanceData` 读取成本、训练时间、移动速度、各时代生命与护甲、近战／远程／火炬／攻城／冲锋攻击档案及升级费用。`RtsStatResolver` 将资料档案与本游戏的文明、地标、王朝、科技和生产来源修正合成单位最终数值；面板、生产、AI 和战斗读取同一结果。资料中未出现的数值沿用 `GameData.UNITS`。

AoE4 页面以地图格和真实秒数描述数值，本游戏地图采用像素且对局节奏较短。当前换算为每格 30 像素、每格每秒 80 像素、训练与研究时间乘 0.55。攻击间隔和伤害值保持来源值。换算参数写在生成的 JSON 顶部，生成脚本中也有对应常量。

### 战斗规则

- 兵种标签分别表示轻重、步骑、近远程、攻城与建筑。来源中的目标加成按所需标签组合匹配，例如「轻型近战步兵」同时要求轻型、近战、步兵。
- 攻击档案分开保存；攻击建筑选用火炬或结构攻击，普通目标选用主攻击。冲锋只作用于单位。长矛兵驻足反冲锋；长弓拒马也可截停冲锋。
- 护甲对每次命中单独结算，因此诸葛弩的三发攻击会分别受到远程护甲影响。远程弹体在命中时结算；有范围的攻击还会伤及周围敌军。
- 单位等级升级由生产建筑研究。尚未研究时，升入新时代不会自动给该兵种较高等级。法兰西的近战武器等级在升时代时自动获得。
- 主动能力由单位保存状态：长弓拒马／万箭齐发、法弩大盾、战船掌舵、携圣物修士招降，以及英格兰侦察兵与重装步兵的预备营地。营地最多五座，增加周围友军视野并提高附近村民狩猎鹿群的收益。

### 文明与地标

兵种模板在 `GameData.UNITS`，文明替换与新增兵种在 `RtsUnitCatalog`。英格兰长弓兵替换弓箭手；法兰西皇家骑士和弩炮手替换对应共享兵种；中国保留普通弓箭手，同时按王朝解锁诸葛弩、火长矛骑兵与掷弹兵。

地标在 `RtsLandmarkCatalog` 描述生产、驻军、防御、研究折扣、资源、侦察和相邻建筑效果，由 `RtsBuilding` 执行。内部 ID 保留旧存档用名称，显示名称使用地标实际名称，例如 `eng_kings_mill` 显示为列王修道院。

铁匠铺科技的名称、时代、成本、效果取自归档的英格兰／法兰西／中国「铁匠铺」建筑页；在 `RtsTechTree` 里定义可玩的科技链。项目之前的四个通用科技仍保留，避免已有对局和测试失效。

本映射覆盖当前可玩的三国与 31 条兵种线。归档中的其余文明、兵种、科技与建筑是后续内容的数据来源，目前不进入运行时，也未宣称逐项复刻原作的所有机制或版本平衡。
