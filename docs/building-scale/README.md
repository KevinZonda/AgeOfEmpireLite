# 建筑 1.6 倍尺寸

2026-10-01：按要求将建筑主体、门窗、高度、碰撞和建造格统一放大到原来的 1.6 倍。人物及骑兵继续使用 0.8 倍显示尺寸，人物碰撞半径保持原值。因此相对最初版本，建筑与人物的视觉尺寸比约为原来的 2 倍（1.6 ÷ 0.8）。

| 项目 | 原建筑尺寸 | 调整后 |
| --- | ---: | ---: |
| 建造格边长 | 25 | 40 |
| 房屋主体 | 48×46 | 76.8×73.6 |
| 城镇中心主体 | 90×90 | 144×144 |
| 房屋地基 | 50×50 | 80×80 |
| 城镇中心地基 | 100×100 | 160×160 |

原有占格数量保持不变。城墙连接距离、攻城塔停靠和测试中的接近距离已适配。这一调整会扩大实际占地，改变可建位置和通道宽度。

## 缓存与验证

建筑尺寸共用 `GameData.BUILDING_SCALE`。复杂模型先在原始尺寸下完成 BSP 排序，再统一缩放源面和排序片段的独立副本；仅在缓存生成时执行，不增加模型面数。投影缓存继续复用。

`tests/building_scale.gd` 检查旋转城门、重复准备时不会再次放大、相邻城墙连接，以及三种文明的 36 个初始单位生成位置。其他验证覆盖放置、经济/军事/市政/防御建筑点击、坡地选择、迷雾记忆、寻路边界、攻城动作和主流程。地标遮挡测试按倍率扩大采样区域，19 个地标/奇观模型及交叉屋翼用例通过。
